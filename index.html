How to allow camera access
  1. Click Start Camera. Your browser shows a permission prompt, usually at the top left of the address bar.
  2. Choose Allow (pick “Allow while visiting” if offered).
  3. If you chose Block: click the camera or lock icon in the address bar, set Camera to Allow, then reload. In Safari: Safari menu, Settings, Websites, Camera.
  4. On a phone: Settings, your browser, Camera, then allow access for this site.
  5. Close other apps using the camera (Zoom, Teams, FaceTime).
  6. The camera works only on https://, localhost or a file opened straight from your computer. In an embedded preview, open the file in its own tab.

    Your submissions

      Data

      Pre-trained pose model data, plus coach-labeled posture rules. Approved exercise requests become new movements to define.

      Model

      MediaPipe Pose finds 33 body landmarks in each camera frame. Rule logic turns joint angles into coaching cues.

      Output

      Live skeleton overlay, rep or hold counter, form accuracy score and written corrections.

      Feedback loop

      Bug reports and exercise requests go to the team’s review queue. Results can later tune thresholds and next week’s volume advice.

      Humans

      You control the camera and can stop any time. Developers review every submission. Physical therapists should set the safety thresholds the coach enforces.
